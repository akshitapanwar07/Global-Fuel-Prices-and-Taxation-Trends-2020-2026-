Project workflow

From Data to Insights

A simple overview of the workflow behind the project.

Project Objective

The objective is to present global fuel prices and taxation in a clear, interactive format. The dashboard supports exploration and comparison, while the story provides a guided way to review the selected views.

1

Data Collection & Extraction

Gather the source data used for fuel prices and taxation comparisons.

2

Data Preparation

Prepare the data for consistent comparisons across countries, fuel types and time periods.

3

Data Visualization

Build charts and views in Tableau to make patterns and comparisons easier to understand.

4

Dashboard & Story Integration

Embed the published Tableau dashboard and story into one accessible project website.

Conclusion

Making Global Fuel Trends Easier to Explore

This project combines interactive charts and a guided story to help viewers examine differences in petrol, diesel and LPG prices, crude oil trends, and fuel taxation. The visualizations support exploration; conclusions should be drawn with the dataset's definitions, coverage and time period in mind.
